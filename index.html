Publicar no GitHub Pages

Hospedagem gratuita para seu projeto web

1

Crie uma conta no GitHub

Acesse github.com e crie sua conta gratuita.

2

Crie um repositório público

Clique em "New Repository", dê um nome e marque como Public.

3

Salve como index.html

Copie o código do Editor e salve com o nome exato index.html.

4

Faça o upload

"Add file" → "Upload files", arraste o arquivo e clique em "Commit changes".

5

Ative o GitHub Pages

Settings → Pages → Branch main → Save.

6

Seu site está no ar!

Em cerca de 60 segundos: https://SEU-USUARIO.github.io/meu-projeto/
