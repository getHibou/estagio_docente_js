Publicar no GitHub Pages

Hospedagem gratuita para seu projeto web

1

Crie uma conta no GitHub

Acesse github.com e crie sua conta gratuita. O GitHub é onde os desenvolvedores guardam e compartilham código.

2

Crie um repositório público

Clique em "New Repository", dê o nome meu-projeto-web e marque como Public.

3

Salve seu arquivo como index.html

Copie o código do Editor, cole num arquivo de texto e salve com o nome exato index.html (não "index.html.txt").

4

Faça o upload do arquivo

No repositório criado, clique em "Add file" → "Upload files", arraste o index.html e confirme com "Commit changes".

5

Ative o GitHub Pages

Vá em Settings → Pages. Em Branch, escolha main e pasta /(root). Clique em Save!

6

Seu site está no ar! 🎉

Em ~60 segundos, seu site estará disponível em:
https://SEU-USUARIO.github.io/meu-projeto-web/
